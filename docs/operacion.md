# Operación 

- **Iniciar la API:** Ejecuta `npm start` en la terminal.
- **Detener la API:** Presiona `Ctrl + C` en la consola.
- **Comprobar que responde:** Ejecuta `curl http://localhost:3000/api/productos`.
- **Identificar errores:** Revisa los mensajes de la consola donde se ejecuta la aplicación.

| Problema | Comprobación | Posible solución |
|---|---|---|
| npm no existe | `npm --version` | Instalar Node.js/npm |
| Faltan dependencias | Revisar error al iniciar | Ejecutar `npm install` |
| Puerto 3000 ocupado | Revisar procesos/puertos | Liberar el puerto |
